Generates a method skeleton for a method referenced by a DataSyncLib annotation string.

Place the caret on a method-name string, such as listener = "onEnergyChange", and invoke Generate referenced method when no method with the expected signature exists.

The method is added to the class declaring the annotated field. Its parameters and return type follow the annotation contract, using the effective managed type for fields with @Conversion. The body contains a default return value when needed.

Supported references include listener, skipWhen, defaultValueGetter, and instance @Codec methods. Implement the generated method body to provide the intended behavior.
